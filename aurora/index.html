A different song every morning

Pick a theme once. Aurora chooses the track, fades it up from silence, and never plays you the same morning twice.

How a morning goes

  1. 06:58SilenceNothing is playing. Aurora has already chosen the track for this morning and has it ready on the device.
  2. 07:00The fade beginsThe track starts far below a normal alarm and rises over about thirty seconds, so waking is a gradient rather than a shock.
  3. 07:00+Full volumeIf you have not moved, it reaches alarm volume. This is still an alarm clock: it is designed to win.
  4. afterSnooze or stopSnooze returns to the same track where it left off. Stop retires the track so tomorrow is a different one.

Will it actually wake me?

This is the only question that matters about an alarm clock, so here is the honest answer. Aurora schedules a real system alarm, plays through the silent switch, and keeps sounding until you stop it. It does not depend on a network: the audio is on the device before the alarm rings, so a plane, a tunnel or a dead Wi-Fi router changes nothing.

What it cannot do is override a phone that is powered off, or a Focus mode you have configured to silence it. On first launch Aurora asks for notification permission and explains why; if you decline, the in-app alarm still rings while the app is open, but you should grant it.

Questions

Can I use my own music?
Yes, with Premium: connect an Apple Music playlist and Aurora shuffles it into the alarm. It needs an active Apple Music subscription. If the app is closed when the alarm fires, it rings with your theme sound first and the playlist starts when you open it — so the alarm never depends on a streaming connection.
Does it need an account?
No. There is no sign-in, no profile and no server. Your alarms live on your device.
Is there a widget?
Yes — Home Screen and Lock Screen widgets show the next alarm and the theme it will use.
Does snooze pick a new song?
No. Snooze continues the same morning. A new track is chosen once per alarm, not once per ring.
